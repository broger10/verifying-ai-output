# Brief and review record

Copy this file for each piece of work. Part 1 is filled before starting. Part 2 is filled by the
reviewers, who did not write the work. Part 3 travels with the deliverable.

---

## Part 1 · Brief (filled before starting)

| Field | Content |
|---|---|
| Goal | What must exist at the end, in one sentence |
| Input | The starting material, with where it is |
| Deliverable | The concrete output |
| Success criteria | How we will know it is done well. Measurable |
| Constraints | Budget, limits, deadlines, required or forbidden choices |
| Out of scope | What will not be done |
| Reserved decisions | What only the owner decides |

**Citation format for this work**

| Kind of source | How it is cited |
|---|---|
| Document | file + page or section |
| Audio / video | file + `[MM:SS]` |
| Screenshot | `SCREEN-nn` |
| Web | address + date of access |
| Data | table and field + the query that reproduces the number |
